# alpha_patterns rules

`alpha_patterns` (`packages/alpha-patterns/src/alpha_patterns/`) — pure chart-pattern geometry over OHLCV bars: swing structure, triple taps, trendlines, wedges, head & shoulders, order blocks, FVGs, causal indicators/oscillators/cycles. **Depends only on `alpha_core`** (import-linter contract `alpha_patterns depends only on core`; numpy/polars allowed). It deliberately contains **no statistics** — it reports what it found and *when that was knowable*; evidence about whether a pattern "works" lives in `alpha_validation`/`alpha_research`. Consumers: `alpha_strategies.rules` (the `rules` strategy's operand indicators; contract `alpha_strategies depends only on core and patterns`) and `alpha_cli.chart_cmds` (`alpha chart overlays`, lazily imported), plus the unit + bias-guard tests; any further CLI/MCP/web consumer follows the "Where do I add X?" rules and needs a new import-linter contract review. Every detector is bias-guarded (`tests/bias_guards/test_hs_no_lookahead.py`, `test_oscillator_no_lookahead.py`, `tests/unit/test_pattern_guards.py`).

This map was derived from module docstrings when the awareness drift guard (`tests/unit/test_repo_awareness_drift.py`) found the package undocumented; keep it in step with the modules.

| `swings.py` · `structure.py` | Fractal swing points with explicit *knowable-at* timing (a swing with lookback `L` is confirmable only `L` bars later); alternating swing sequences and break-of-structure | `Swing`, `find_swings`, `swings_known_by`; `StructureBreak`, `swing_sequence`, `break_of_structure`, `last_pivot_before`, `extreme_between` |
