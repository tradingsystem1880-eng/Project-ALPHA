# alpha_patterns rules

`alpha_patterns` (`packages/alpha-patterns/src/alpha_patterns/`) — pure chart-pattern geometry over OHLCV bars: swing structure, triple taps, trendlines, wedges, head & shoulders, order blocks, FVGs, causal indicators/oscillators/cycles. **Depends only on `alpha_core`** (import-linter contract `alpha_patterns depends only on core`; numpy/polars allowed). It deliberately contains **no statistics** — it reports what it found and *when that was knowable*; evidence about whether a pattern "works" lives in `alpha_validation`/`alpha_research`. No app layer imports it yet (consumers are the unit + bias-guard tests); adding a CLI/MCP/web consumer follows the "Where do I add X?" rules and needs a new import-linter contract review. Every detector is bias-guarded (`tests/bias_guards/test_hs_no_lookahead.py`, `test_oscillator_no_lookahead.py`, `tests/unit/test_pattern_guards.py`).

This map was derived from module docstrings when the awareness drift guard (`tests/unit/test_repo_awareness_drift.py`) found the package undocumented; keep it in step with the modules.

| Module | Responsibility | Key public symbols |
|---|---|---|
| `series.py` | The one validated OHLCV container every detector consumes (finite, ordered, OHLC-consistent — fail-loud in one place) + shared derived measures | `OHLCV`, `true_range`, `atr`, `rolling_vwap`, `rolling_min`, `rolling_max` |
| `swings.py` · `structure.py` | Fractal swing points with explicit *knowable-at* timing (a swing with lookback `L` is confirmable only `L` bars later); alternating swing sequences and break-of-structure | `Swing`, `find_swings`, `swings_known_by`; `StructureBreak`, `swing_sequence`, `break_of_structure`, `last_pivot_before`, `extreme_between` |
| `triple_tap.py` · `trendline.py` · `wedge.py` · `head_shoulders.py` | Study 1 triple-tap lows (every free parameter explicit); Study 2 algorithmic descending trendlines and breaks (constrained to information available at the time); converging trendline pairs with computed apex; H&S / inverse / Quasimodo one detector, four variants | `TripleTapConfig`, `TripleTap`, `detect_triple_taps`, `detect_nth_taps`; `TrendlineConfig`, `Trendline`, `TrendlineBreak`, `build_trendlines`, `find_breaks`; `WedgeConfig`, `Wedge`, `detect_wedges`, `wedge_lines`, `WedgePanel`, `wedge_panel`; `HSConfig`, `HSEvent`, `detect_head_shoulders` |
| `context.py` · `levels.py` | Market-structure conditioning variables (order blocks, fair-value gaps, MA/VWAP trend state, location) and horizontal levels (Fibonacci grids, round numbers) | `OrderBlock`, `FairValueGap`, `find_order_blocks`, `find_fair_value_gaps`, `trend_state_ma`, `trend_state_vwap`, `distance_from_low`; `FibGrid`, `fib_levels_at`, `nearest_fib_distance`, `round_levels`, `round_number_distance` |
| `indicators.py` · `oscillators.py` · `cycles.py` | Trailing-window indicators, classical oscillators/channels rebuilt causally (OBV, MACD, stochastics, ADX, Ichimoku, Keltner/Donchian, squeeze), and memory/mean-reversion statistics (autocorrelation, variance ratio, Hurst, dominant cycle) | `rolling_mean`, `rolling_std`, `log_returns`, `realized_volatility`, `bollinger_bandwidth`, `rsi`, `percentile_rank`, `rolling_correlation`, `LeadLag`, `cross_correlation_lags`, `CalendarFeatures`, `calendar_features`, `consolidation_length`, `volume_ratio`; `ema`, `wilder_smooth`, `on_balance_volume`, `MACD`, `macd`, `Stochastic`, `stochastic`, `williams_r`, `typical_price`, `money_flow_index`, `chaikin_money_flow`, `DirectionalIndex`, `directional_index`, `Channel`, `keltner_channel`, `donchian_channel`, `Ichimoku`, `ichimoku`, `squeeze`; `autocorrelation`, `rolling_autocorrelation`, `VarianceRatio`, `variance_ratio`, `hurst_exponent`, `hurst_random_walk_reference`, `Cycle`, `dominant_cycle`, `rolling_variance_ratio`, `rolling_hurst` |
| `controls.py` · `synthetic.py` | Matched control sampling (the comparison that turns a statistic into evidence) and synthetic series with *known* injected patterns — the detectors' ground truth | `MatchedControls`, `sample_matched_controls`; `geometric_brownian_series`, `inject_triple_tap`, `inject_descending_trendline`, `inject_head_shoulders`, `WedgeTruth`, `inject_wedge` |
