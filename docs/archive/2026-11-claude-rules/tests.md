# Test-layer rules

- Placement: `tests/unit/` (pure), `tests/integration/` (CLI/engine), `tests/bias_guards/` (every data/strategy unit gets a `@pytest.mark.bias_guard` future-poison test; each guard has a must-fail leaky twin so a vacuous guard is itself detected — see `tests/bias_guards/test_future_poison_pattern.py`), `tests/oracles/` (metamorphic / calibration / differential; `oracle`, `slow_oracle`), `tests/acceptance/` (visible behaviour tests of the gauntlet and statistics contracts; ADR-0041).
- Markers are strict (`--strict-markers`): `bias_guard`, `network`, `oracle`, `slow_oracle`, `holdout` (carried only by `tests/acceptance/`), `platform` (auto-applied by `tests/conftest.py` from `tests/_tiers.py::classify_platform`; `gate.py check --all` runs the fast tier `-m "not platform"`, CI runs everything under `pytest-xdist -n auto`). Goldens live in `tests/fixtures/`; statistical goldens carry tolerances, never exact float equality.
- `tests/unit/test_claude_harness_*.py`, `tests/bias_guards/**`, and `tests/oracles/**` are protected control plane (changed only in a reviewed pull request; CI is the merge gate).
- A test that cannot run is reported `UNVERIFIED:`; failing output is quoted verbatim.
- Linux tests that need external orphan reaping use `@pytest.mark.usefixtures("owned_test_process")` before spawning processes and join the owner acceptance cases in `test_gate_process_supervisor.py`. Run them through `scripts/run_owned_test.py`. Ordinary subprocess tests, tests whose parents reap their own children, and tests exercising the wrapper itself do not need this fixture.
- Quant-rigor sweeps (`scripts/gate.py`): `mutate [modules|--all]` (mutmut per module in a staged tree; kill-rate ≥ 0.90 or the module's recorded `.claude/mutation-baseline.json` floor, whichever is lower; `--write-baseline` changes are reviewed in the pull request), `semgrep [--changed]` (`.semgrep/alpha.yml`), `determinism` (goldens/identity/determinism tests twice under perturbed `PYTHONHASHSEED`/`TZ`), `raise-cov [--fail]` (unexercised `raise` sites in quant modules; 177/576 unreached at the 2026-08-19 baseline, so nightly runs it report-only). CI's backend job runs Semgrep and adds slow oracles + the mutation gate only when a quant SOURCE module changed; `.github/workflows/nightly.yml` keeps Semgrep, determinism and raise-cov; the owner-selected weekly exhaustive mutation sweep uses `.github/workflows/mutation-weekly.yml`, isolated deterministic mutant fragments, at most eight jobs and two mutmut workers per job, identity-bound checkpoints and exact aggregation (a module's `timeout`/`no_tests` mutants are never credited as kills; minimum 0.90, tolerance 0.005 and baseline floors stay unchanged).
