# Multi-agent specialist swarm / PydanticAI migration

**Status:** Idea
**Rough size:** L

## Problem / why

Several plans deferred an unbounded specialist swarm and a PydanticAI migration "pending evidence
that typed handoffs and existing isolated runtime are insufficient". The current rule is
deterministic tools and Codex first; a specialist is admitted only for a measured gap.

## What "done" looks like

A measured weakness in the bounded controller is shown first. Then a matched comparison of the
current path against a typed multi-agent handoff, adopted only on quality or efficiency gain, with
no new authority over data, promotion or execution.

## Dependencies

Measured evidence from the bounded research controller and evaluation suite; the specialist
adoption rule in the checklist.
