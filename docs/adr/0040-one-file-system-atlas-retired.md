# ADR-0040: One file system; the Atlas graph, viewer and gate component are retired

**Status:** Accepted
**Date:** 2026-11-13
**Deciders:** Project ALPHA owner and AI build agents

## Context

An agent looking for context met four overlapping mechanisms: the operating manual and path
rules, the context maps under `docs/context/`, the dated plans and build history, and Atlas.
It also met three indexes: the Atlas graph (`architecture/atlas/generated/graph.json`, 2.7 MB,
with generated Mermaid maps in `docs/atlas/`), the August session brief and
`.alpha/state/repo-index.json` (`scripts/harness_awareness.py`), and Atlas's developer index
behind `gate.py orient`.

- **No agent read the graph.** Agents used `gate.py orient` and grep. The FastAPI + React viewer
  and its prompt packs had no caller in the agent loop.
- **Freshness churn.** The graph's freshness check was a required CI component (`atlas`) and a
  preflight blocker, so any source or documentation edit had to regenerate it: 85 of the 206
  commits from 2026-10-01 to the retirement base `15df9856` touched the generated graph. The repo index could not even be regenerated by the navigator agent that was
  told to read it.
- **The "context filesystem" was a search tool inside Atlas.** The 2026-10-30
  [queryable context filesystem plan](../superpowers/plans/archive/2026-10/2026-10-30-queryable-context-filesystem.md)
  read the Interpretable Context Methodology (arXiv 2603.16021) and rejected its structure
  (small routing files and numbered stage folders) "in favor of on-demand Atlas views". The
  resulting `alpha_atlas.context` query issued hash-bound, expiring receipts that nothing
  consumed. Only two small parts were useful: the orientation summary and the document search,
  and the search depended only on the repository paths, not on the graph.

## Decision

- **Retire** the Atlas graph and its generator, the viewer and prompt packs, the generated
  diagrams, the curated definitions, `tests/unit/test_atlas_consistency.py`, the `atlas` gate
  component and CI job, and preflight `atlas_freshness`. Retire the legacy session brief and repo
  index (`gate.py brief`, `gate.py index`).
- **Keep orientation and search** as `scripts/fs.py` (stdlib only, strict mypy, listed in
  `gate.HARNESS_SCRIPTS`):
  - `fs.py orient` (`scripts/fs_orient.py:orientation`; `gate.py orient` delegates to it) lists
    components, module counts and the routing documents (`CLAUDE.md`, `docs/README.md`,
    `docs/roadmap/README.md`, `docs/context/README.md`) within the same 6 KB cap.
  - `fs.py search` (`scripts/fs_search.py:search`) returns ranked excerpts of Git-tracked,
    allow-listed documentation with path, heading, line range, kind and lifecycle. Live
    documents rank ahead of archived history (`docs/archive/`, `docs/records/`,
    `docs/build-status/`, `docs/superpowers/plans/archive/`, `docs/BUILD-STATUS.md`). Untracked
    files, symlinks, owner data and tests are never read. There are no receipts.
- **One name.** The single documentation and routing system is called **the file system**. A
  following change restructures it on the Interpretable Context Methodology, adapted to a
  codebase: a small identity file, small routing files, a `CONTEXT.md` per area, and numbered
  stage folders for the delivery and research pipelines.

## Consequences

- CI gate components go from six to five (backend, frontend, literature, qlib, eval). Branch
  protection must require `ci-ok` (ADR-0039) before this change merges; a required `atlas` check
  would otherwise wait forever.
- Commits no longer regenerate a graph; preflight no longer blocks on it.
- Context receipts no longer exist. A search result is a pointer to read, not evidence; anything
  that needs evidence cites the source file and commit.
- Items H26 and H60 of the mirrored
  [feature readiness checklist](../context/feature-readiness-checklist-2026-10-27.md) are
  superseded by this record; the mirror itself is not edited.
- Tests: `tests/unit/test_fs_search.py`, `tests/unit/test_fs_orient.py`;
  `tests/unit/test_repo_awareness_drift.py` now uses `fs_orient.orientation`.
- This retires [ADR-0037](0037-agent-neutral-research-engineering.md)'s "optional Atlas views"
  and the generated session brief and repo index of
  [ADR-0034](0034-agent-operating-system-v2.md) (item 4); their other decisions stand.
