ceiling (34) admits no new live plan, and the work was finished in one sitting.

## For the owner

- A new check stops any new product source file from passing 1,500 lines and any new function
  from passing 150 lines. Tests are not measured.
- Today's 10 oversized files and 98 oversized functions are written down at their exact size. They
  may not grow; when one shrinks, the record must be lowered to match; when it falls under the
  limit, its line must be removed. The list can only get shorter.
- Nothing changes in the app, and no research approval is touched.

## Test plan

Four tree tests (new files, new functions, exact baseline, no entry added or raised since `origin/main`) and seven unit tests of the measurer on small
sources (nested, method, async, decorators not counted, same-name definitions, a file that does not parse, the growth comparison). The tree tests were run
against a deliberately edited baseline to see each failure message.
