# Documentation index

Where each kind of document lives, and how long it stays current. Start with
[`AGENTS.md`](../AGENTS.md) and [`CLAUDE.md`](../CLAUDE.md); the [context index](context/README.md)
maps capabilities to their owning documents.

## Lifecycle

| State | Meaning | Edited how | Where |
|---|---|---|---|
| Living | Describes the system or a procedure as it is now | Updated in place when behaviour changes | `ARCHITECTURE.md`, `context/`, `governance/` (hand-written files), `operations/` |
| Decision | Records a choice and its reasons | Decision text is not rewritten; dated status notes and forward links are added when a newer record supersedes it | `adr/` |
| Intent | Dated design or plan for a piece of work | Status lines updated; finished plans are marked `**Delivery state:** Completed` | `superpowers/specs/`, `superpowers/plans/` |
| Record | True as of its date; kept for provenance | Appended to or left as-is; path-only link fix-ups allowed | `BUILD-STATUS.md`, `build-status/`, `records/`, `operations/retrospectives/` |
| Archive | No longer current; kept for history | Not edited | `archive/` |
| Generated | Produced by a tool; never hand-edited | Regenerated by its command (below) | `atlas/`, parts of `governance/` |

## Folders

| Path | What belongs there |
|---|---|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Current package boundaries, layered DAG and runtime components. |
| [`BUILD-STATUS.md`](BUILD-STATUS.md) | Append-only delivery history from 2026-10-01, in date order. New delivery records go at the end. |
| [`build-status/`](build-status/) | Quarterly archives of older `BUILD-STATUS.md` entries, moved verbatim: [2026 Q2](build-status/2026-Q2.md), [2026 Q3](build-status/2026-Q3.md). |
| [`adr/`](adr/README.md) | Architecture decision records `NNNN-*.md`; the README is the index and supersession map. |
| [`context/`](context/README.md) | Navigation maps for the Software Team and ALPHA Quant Platform, and the canonical [feature readiness checklist](context/feature-readiness-checklist-2026-10-27.md) (the full-scope owner). |
| [`governance/`](governance/README.md) | Capability/authority matrix, OpenAPI operation classification, dependency licences, risk register and provenance records. |
| [`operations/`](operations/README.md) | Living runbooks and operating guides (development loop, harness, research workflows, Monte Carlo guides). |
| [`operations/retrospectives/`](operations/retrospectives/) | Dated retrospectives `YYYY-MM-DD-<slug>.md` with a `## Watch-outs` section; the newest one feeds the session brief. |
| [`records/`](records/README.md) | Dated one-off records: owner decisions and exceptions, delivery notes, handovers, [audits](records/audits/) and [investigations](records/investigations/). |
| [`superpowers/specs/`](superpowers/specs/) | Dated design specs. |
| [`superpowers/plans/`](superpowers/plans/) | Feature plans `YYYY-MM-DD-<slug>.md` with a fenced JSON `FeaturePlan` block (`gate.py plan-check`); the harness reads this folder flat. |
| `roadmap/` | Added in Phase 3. |
| [`atlas/`](atlas/) | Generated Mermaid maps of the system. |
| [`assets/`](assets/) | Images referenced by documentation. |
| [`archive/`](archive/README.md) | Historical prompts, one-off research and old run output, with a table of where each file came from. |

## Generated files

Do not edit these by hand; rerun the command and commit the result.

| Files | Command |
|---|---|
| `docs/atlas/*.md` (and `architecture/atlas/generated/`) | `cd tools/alpha-atlas && uv run python -m alpha_atlas.generate` (`--check` verifies freshness) |
| `docs/governance/capability-authority-matrix.md`, `docs/governance/openapi-operation-classification.json` | `uv run python scripts/check_openapi_operations.py --write` (without `--write` it checks) |

Atlas also reads `adr/`, `superpowers/specs/` and other documentation folders as inputs, so
regenerate it after changing them.
