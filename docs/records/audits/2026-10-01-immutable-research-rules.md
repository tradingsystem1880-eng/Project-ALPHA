# Immutable rules: implementation and evidence boundaries

The bounded controller now accepts canonical embedded rule specifications alongside momentum.
The same exact UTF-8 bytes and SHA-256 reach baseline and validation; collected manifests must
match. Mutable saved names are used only when preparing a plan, never resolved during execution.
Named-rule commands and the strategy/statistical implementations are unchanged.

Targeted tests cover both real CLI paths, changed saved names, invalid/file/hash combinations,
noncanonical bytes, changed files between stages, replay, and missing/different rule metadata
in both run types. Existing budget, process cleanup, snapshot/cutoff and denial-accounting checks
remain applicable. Canonical acceptance requires matching external full-gate/review receipts;
this document does not substitute for them.

The retained VEGA MACD/Bollinger recipe is an operator smoke input. Its measured results and
artifact hashes are retained separately in the dated delivery evidence. A completed negative
validation is useful evidence; it does not establish an edge. No fresh agent trial, multi-turn
pressure test, PydanticAI transport comparison or speedup claim is made. Historical Claude results
are unchanged. The main checkout's concurrent UI/rule-explanation work remains separate.

Default launch-form catalog exclusion does not prevent the existing authorized generic CLI
transport from relaying the new local file/hash options. No new REST schema, MCP tool or owner
permission was introduced. The controller remains non-admitting and CASH/long-only. Rules with
short conditions do not enable short positions.

## What remains

The next correctness boundary is a physically cutoff-restricted dataset for a fresh agent context.
An as-of flag cannot remove future data already seen by the caller. After deterministic access
probes pass, use bounded Codex-only trials to test complete multi-turn stopping behavior. Specialist
reviewers should consume these verified artifacts under explicit budgets; introducing more agents
before measuring their marginal value would add cost without fixing these boundaries.

## Efficiency interpretation

Source inspection (not CPU profiling) shows that unchanged validation defaults perform 1,000
Tier-1 synthetic paths, 64 full-engine paths and two 2,000-resample intervals. Rule evaluation
recomputes trailing indicators. These are plausible runtime contributors; attributing runtime
requires stage timings or profiling. The controller reduces orchestration and prevents repeated
unplanned work; it does not reduce this statistical workload or establish a measured speedup.
