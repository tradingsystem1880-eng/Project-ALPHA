# Dated records

Point-in-time records: owner decisions and exceptions, delivery notes, handovers, audits and
investigations. Each file is true **as of its date** and is kept for provenance; it is not current
policy, a runbook or acceptance evidence for later trees. Records are not rewritten — later facts
go in a new record or in [`docs/BUILD-STATUS.md`](../BUILD-STATUS.md). Path-only link fix-ups are
the one exception.

Living runbooks stay in [`docs/operations/`](../operations/README.md). The files below moved here
from `docs/operations/`, `docs/context/`, `docs/audit/` and `docs/investigations/` on 2026-11-13;
records still linked from `CLAUDE.md` (for example the 2026-11-05 offline funding delivery) stay
in `docs/operations/`. Atlas context queries read this folder as `history`.
